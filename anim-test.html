Тест плавности обоев Type-live / Smoothness test of slow-drifting backgrounds

Откройте этот файл в Firefox (и потом в Edge). Масштаб страницы оставьте 100%. Смотрите на каждый квадрат по 10–15 секунд. В квадратах одни и те же буквы, различается только способ движения.
Напишите: какие номера двигаются плавно (без рывков и дрожи), и какие хуже всего.
EN: open in Firefox at 100% zoom, watch each square for 10–15 s. Same letters, only the way of moving differs; see which ones glide and which tremble.
